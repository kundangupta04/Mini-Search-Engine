# Mini Search Engine Using Data Structures and Algorithms

A search engine built with a Trie, HashMap-based Inverted Index, ranking and Merge Sort.

## Run

    npm run install:all
    npm run dev

Client: http://localhost:5173
Server: http://localhost:5000/api/health






# Route       →  "Which URL goes to which function?"

# Controller  →  "Read the request, call the service, send the response"

# Service     →  "Do the real work" (no knowledge of HTTP)
